# Sécurité

Ne signalez jamais une faille de sécurité dans une issue ou une pull request : elles sont publiques.

Utilisez le signalement privé de GitHub : dans le dépôt concerné, onglet **Security**, bouton
**Report a vulnerability**. Seuls les responsables du dépôt voient le signalement.

## Security

Never report a vulnerability in an issue or a pull request: they are public. Use GitHub's private vulnerability
reporting instead: in the repository, **Security** tab, **Report a vulnerability**. Only the maintainers see the report.
